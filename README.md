# lifecareer

人生・キャリアに関する情報や記録を、長期的に整理・管理するためのリポジトリ。

## 目的

- 自分の価値観、目標、経験、振り返りを記録する
- キャリアと生活の両方を見通し、必要に応じて計画を更新する
- 情報を一元的に管理し、後から参照・再利用できる状態にする

## AIエージェント

AIエージェントは作業前に [AGENTS.md](AGENTS.md) を確認すること。Claude Code向けの追加指示は [CLAUDE.md](CLAUDE.md) に記載する。

## 基本方針

- 必要以上に細分化せず、シンプルな構成を維持する
- 同じ情報を複数の文書で重複管理しない
- 最初から完璧な分類を求めず、必要に応じて整理する
- 一時的な資料と正式な文書を区別する
