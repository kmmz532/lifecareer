# 情報管理

## 情報の区別

記録では、次の情報を混同しない。

- **事実**: 実際に起きたこと、確認できる情報
- **解釈**: 事実に対して本人がどのように捉えたか
- **仮説・予定**: まだ確認されていない考えや今後の計画

必要に応じて、情報がいつ時点のものか、どこから得たものかを記録する。

## 正確性

- 不明な情報を推測で補完しない。
- 数値や実績は、対象範囲や集計条件が分かるようにする。
- 時間とともに変化する情報は、いつ時点の情報かを明確にする。
- 古い情報を現在も有効な情報として扱わない。

## 情報の一元管理

- 同じ情報の正本は原則として一つにする。
- 他の文書で必要な場合は、正本へのリンクや要約を利用する。
- 同じ情報を複数箇所で更新する運用を作らない。
- 複数の記録が矛盾する場合は、根拠や時点を確認して整理する。

## 出典・根拠

- 外部情報や第三者の情報を記録する場合、可能な範囲で出典を残す。
- 本人の発言・経験に基づく記録と、外部資料に基づく情報を区別する。
- AIが生成・整理した内容を、本人が確認した事実として扱わない。

## 個人情報

- 管理する必要のない個人情報は記録しない。
- 認証情報、パスワード、秘密鍵、トークンなどを保存しない。
- 外部に公開する可能性を考慮し、公開範囲に適さない情報を含めない。
