# 文章作成

## 基本方針

- 読み手が内容を把握しやすい、簡潔で具体的な文章を使う。
- 一つの段落では、原則として一つの主題を扱う。
- 意味のない装飾や過剰な見出し分割を避ける。
- 文書の目的に応じて、箇条書き・表・文章を使い分ける。

## Markdown

- 見出しは階層順に使用し、見出しレベルを飛ばさない。
- 文書のタイトルは原則として `#` から始める。
- 手順は順序付きリスト、並列項目は箇条書きを使う。
- ファイルやディレクトリへのリンクは、可能な限り相対パスを使用する。
- コードや設定値はコードブロックで囲み、必要に応じて言語を指定する。

## 表現

- 本文は原則として日本語で記述する。
- 技術用語や固有名詞は、一般的な表記を使用する。
- 日付や数値は、誤解が生じない形式で記述する。
- 事実と意見・推測を同じ表現で断定しない。
- 本人の発言や文章を引用・編集する場合、本人の意図やニュアンスを変えない。

## 文書の構成

- 冒頭で文書の目的や対象を明確にする。
- 詳細な説明が必要な場合も、最初に全体像を示す。
- 関連する情報が別文書にある場合は、重複して書かずリンクする。
