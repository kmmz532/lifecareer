# ドキュメントガイド

このディレクトリでは、人生・キャリアに関する情報や記録を管理する。

## ディレクトリ

- [rules/](rules/): 文書の管理・作成に関するルール
- [templates/](templates/): 繰り返し利用する文書のテンプレート

## 文書を追加するとき

1. 既存の文書に追記できないか確認する。
2. 内容に合った配置先を選ぶ。
3. [文書管理ルール](rules/document-management.md)に従ってファイルを作成する。
4. 必要に応じて、このREADMEや各ディレクトリのREADMEからリンクする。

最初からすべての情報を分類・文書化する必要はない。実際に必要になった情報から追加し、構成は利用状況に応じて見直す。
